## Install

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyotaah/lucidui/main/dist/lucidui.lua"
))()
```

`dist/lucidui.lua` is auto-generated by `build.py` from `src/` on every push. A GitHub Action rebuilds it automatically.

---

## Quick Start

Ten lines to a working hub:

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyotaah/lucidui/main/dist/lucidui.lua"
))()

local Window = LucidUI:CreateWindow({ Name = "My Hub" })
Window:BuildSettingsPanel()

local Tab     = Window:CreateTab({ Name = "Main", Icon = "zap" })
local Section = Tab:CreateSection({ Name = "Features", StartExpanded = true })

Section:CreateButton({
    Name = "Click Me",
    Callback = function()
        LucidUI:Notify({ Title = "Done", Message = "You clicked the button." })
    end,
})
```

## Features

- **Glass-morphism design** — rounded translucent panels, specular gradients, accent glow
- **Animated intro** — loading card with shimmer progress, skippable with a click
- **7 preset themes** — Default, Light, Nebula, Midnight, Dracula, Tokyo Night, Forest
- **Live theming** — colors cross-fade over 0.3s when switched
- **Custom theme editor** — 6 color pickers, saved as JSON
- **Config slots** — save, load, and delete named profiles. The `default` slot is locked
- **Background images** — asset IDs, `rbxassetid://` URLs, and direct `https://` links
- **Auto accent detection** — hue-histogram sampling picks a matching color from any image
- **Glass notifications** — toasts with adaptive accent bars
- **Premium polish** — ripple on press, glow on hover, quiet UI sounds
- **Mobile-friendly** — touch drag, responsive scaling, compact mode
- **Traffic-light controls** — minimize to header or collapse to a floating pill
- **25 frame-based icons** — render identically on every device
- **Cross-executor** — tested on Delta, Solara, Wave, Xeno, Krnl, Fluxus, Synapse

## Elements

All elements accept an optional `Flag` string. If set, the value is saved with the config.

### Button

```lua
Section:CreateButton({
    Name = "Click Me",
    Callback = function()
        print("Button clicked")
    end,
})
```

### Toggle

```lua
Section:CreateToggle({
    Name = "Enable Feature",
    CurrentValue = false,
    Flag = "EnableFeature",
    Callback = function(state)
        print("Toggled:", state)
    end,
})
```

### Slider

```lua
Section:CreateSlider({
    Name = "Speed",
    Range = {1, 100},
    Increment = 1,
    CurrentValue = 50,
    Flag = "Speed",
    Callback = function(value)
        print("Speed:", value)
    end,
})
```

### Dropdown

```lua
Section:CreateDropdown({
    Name = "Mode",
    Options = { "Balanced", "Performance", "Quality" },
    CurrentOption = "Balanced",
    Flag = "Mode",
    Callback = function(option)
        print("Mode:", option)
    end,
})
```

### Keybind

```lua
Section:CreateKeybind({
    Name = "Toggle Menu",
    CurrentKeybind = Enum.KeyCode.RightShift,
    Flag = "MenuKey",
    Callback = function(key)
        print("Bound to:", key.Name)
    end,
})
```

Click the box, then press a key to bind it. Click again to rebind. Tap outside to cancel.

### Input

```lua
Section:CreateInput({
    Name = "Username Filter",
    Placeholder = "type here...",
    Flag = "UsernameFilter",
    Callback = function(text)
        print("Filter:", text)
    end,
})
```

### TextDisplay

```lua
Section:CreateTextDisplay({
    Title = "Info",
    Content = "This block auto-sizes with its content.",
})
```

Update it later:

```lua
local display = Section:CreateTextDisplay({ Title = "Status", Content = "Booting..." })
display:Set("Running")
display:SetTitle("Status")
```

## Themes

Switch with `Window:SetTheme("Nebula")` or through the gear menu.

| Theme | Description |
|---|---|
| Default | Dark glass, blue accent |
| Light | Clean light mode |
| Nebula | Purple cosmic palette |
| Midnight | Deep blue with soft edges |
| Dracula | Classic purple on charcoal |
| Tokyo Night | Muted indigo tones |
| Forest | Green glass |

Open **gear icon → Custom Theme** to build your own. Six color pickers apply live. Click **Save As** to store the theme. Saved themes appear in the Theme dropdown and in the Saved Themes list. Click the `x` to delete.

## Background Images

Open **gear icon → Background Image**. Supports:

- **Asset IDs** — `12345678`
- **Asset URLs** — `rbxassetid://12345678`
- **Direct image URLs** — `https://i.imgur.com/XXXXX.jpg`

HTTP URLs require `getcustomasset` and `writefile` in your executor. If either is missing you get a toast telling you so.

**Auto Accent** samples the image, runs a hue-histogram over saturated pixels, and applies the dominant color as the UI accent. Works best on images with strong, saturated colors.

## Config System

Every element with a `Flag` string gets saved to `LucidUI/Configs/<slot>.json`. The `default` slot is locked and cannot be deleted.

```lua
Window:SaveConfig("slot1")
Window:LoadConfig("slot1")
```

Custom themes save to `LucidUI/Themes/<name>.json`.

The full layout:

```
LucidUI/
├── Configs/
│   ├── default.json         (locked)
│   └── <custom slots>.json
├── Themes/
│   └── <theme names>.json
└── bg_<timestamp>.png        (downloaded background images)
```

## Intro Screen

Shown automatically when the window is created. Toggle with `IntroEnabled = false`.

```lua
LucidUI:ShowIntro({
    Title       = "Loading",
    Subtitle    = "v1.0.0",
    Tagline     = "Preparing interface",
    Duration    = 2.8,
    SkipOnInput = true,
    OnComplete  = function()
        print("Intro finished")
    end,
})
```

For long operations, pass custom stages that report progress:

```lua
LucidUI:ShowIntro({
    Stages = {
        { text = "Loading modules...",    pct = 0.20, task = function() task.wait(0.5) end },
        {
            text = "Downloading assets...",
            pct  = 0.90,
            task = function(report)
                for i = 1, 10 do
                    task.wait(0.1)
                    report(i / 10)
                end
            end,
        },
        { text = "Ready", pct = 1.00, task = function() task.wait(0.4) end },
    },
})
```

Each `task` receives a `report(subProgress)` callback. Call it with a value 0–1 to advance the bar mid-stage.

## Executor Support

LucidUI uses standard Roblox APIs plus a `Compat` layer around file operations. If your executor runs Roblox scripts at all, there's a very good chance it works here.

**Desktop** — Xeno, Delta, Wave, Swift, Cryptic, Solara, Synapse Z, KRNL, Fluxus, JJSploit, Potassium, Velocity, Hydrogen

**Mobile** — Delta, Arceus X, Codex, Fluxus, E-Sign (iOS)

Only three features depend on executor-specific APIs:

- **Config saving** → `writefile`, `readfile`, `isfolder`, `makefolder`
- **Background image from HTTP** → `getcustomasset`, `writefile`
- **Auto accent detection** → `AssetService:CreateEditableImageAsync`

If any of those are missing, LucidUI shows a toast and the rest of the UI keeps working.

## Development

### Build

```bash
python build.py
```

Concatenates every `src/*.lua` in sorted order into `dist/lucidui.lua`. GitHub Actions runs this on push to `main`.

### Module structure

```
src/
  00_compat.lua         Compat layer + JSON serialization
  01_helpers.lua        Services, easing, constructors, glass
  01b_polish.lua        Ripple, hover glow, UI sounds
  02_themes.lua         7 preset themes + derivation
  03_icons.lua          Frame-based gear icon
  04_intro.lua          Animated intro screen
  05_notifications.lua  Glass toast system
  06_window.lua         Window shell, drag, resize, settings container
  07_settings_a.lua     Theme dropdown, custom theme, saved themes
  07_settings_b.lua     Background, auto accent, configs, about
  08_tab.lua            Tabs, sections, 25 icons
  09_elements.lua       Button, Toggle, Slider, Dropdown, Keybind, Input
```

### Testing locally

There's no unit test suite. Test against a live Roblox session — either in a game or Studio with the executor injected.

## Contributing

Open an issue or PR. Two ground rules:

1. **Keep the `Compat` layer in mind.** Anything that touches the file system must go through `Compat.hasFS()`, `Compat.write()`, `Compat.read()`, etc.
2. **No external dependencies.** LucidUI is a single `loadstring`. Everything must work with just Roblox APIs.

When proposing a new element, include a preview snippet in the PR description showing how it looks and how it's used.

## FAQ

**Is this a fork of Luna or Starlight?**
No. LucidUI was built from scratch as a clean alternative after those libraries were deprecated or proved unreliable across executors. The API is intentionally similar so migration is easy.

**Can I use this in a paid script?**
Yes — MIT license. Attribution is appreciated but not required.

**Does it work on mobile?**
Yes. Every widget is touch-compatible, and the window auto-scales to viewport size.

**Why does background image loading fail on some executors?**
The HTTP download path needs `getcustomasset` and `writefile`. If your executor lacks either, the feature is unavailable — but everything else still works. Asset IDs (`rbxassetid://...`) work without those functions.

**Can it be skidded?**
Yes, any Lua script that runs in an executor can be read and re-run. There's no realistic protection against this — it's a property of the platform, not a LucidUI limitation.

**The dropdowns aren't collapsing / sections stutter / keybinds don't capture.**
Check the issues tab. If the bug isn't filed, open a new one with the exact console output and a description of what you did.
