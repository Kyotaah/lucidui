# LucidUI

**A modern, glass-morphism interface library for Roblox.**

Built for stability, cross-executor compatibility, and a premium look — no deprecated dependencies, no key systems, no bloat. Just a clean UI you can drop into any script hub.

## Why LucidUI?

Most Roblox UI libraries are either abandoned, buggy on half the executors, or so heavy they lag the game. LucidUI was built out of frustration with all three. It's a single `loadstring` with zero external dependencies, and it gracefully degrades when the executor doesn't support something (like file I/O) instead of erroring out.

Here's what you get:

- **Glass-morphism design** — rounded translucent panels, specular gradients, accent glow. It doesn't look like every other script hub.
- **Animated intro screen** — a loading card with shimmer progress that plays before your window appears. Skip it with a click.
- **Live theme editor** — 6 editable colors, real-time preview, saved as JSON. No restarting your script to see changes.
- **Config slots** — multiple saved profiles. The `default` slot is locked so users can't accidentally brick their setup.
- **Background image support** — asset IDs, `rbxassetid://` URLs, or direct HTTP(S) links via `getcustomasset`.
- **Auto accent detection** — sample an image's pixels with `EditableImage` and LucidUI picks a matching accent color for you.
- **Notification system** — glass toasts that slide in from the top-right with adaptive accent bars.
- **Mobile-friendly** — touch drag, viewport-responsive scaling, compact mode. Works on phones without feeling cramped.
- **Minimize to pill** — the X button collapses the window to a floating draggable pill instead of closing it forever.
- **Actually cross-executor** — see the list below. It's the whole point.

## Install

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyootah/lucidui/main/dist/lucidui.lua"
))()
```

> `dist/lucidui.lua` is auto-generated by `build.py` from the `src/` folder. If it doesn't exist yet, run the build or grab a release.

## Quick Start

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyootah/lucidui/main/dist/lucidui.lua"
))()

local Window = LucidUI:CreateWindow({
    Name = "My Hub",
    Width = 620,
    Height = 460,
})

Window:BuildSettingsPanel()

local MainTab = Window:CreateTab({ Name = "Main" })
local Section = MainTab:CreateSection({
    Name = "Options",
    Collapsible = true,
    StartExpanded = true,
})

Section:CreateToggle({
    Name = "Enable Feature",
    CurrentValue = false,
    Flag = "MyFeature",
    Callback = function(state)
        print("Toggled:", state)
    end,
})

Section:CreateSlider({
    Name = "Speed",
    Range = {1, 100},
    Increment = 1,
    CurrentValue = 50,
    Flag = "Speed",
    Callback = function(value)
        print("Speed:", value)
    end,
})

Section:CreateButton({
    Name = "Do Thing",
    Callback = function()
        LucidUI:Notify({ Title = "Done", Message = "Action completed" })
    end,
})
```

That's a full working hub. Everything else in the API docs below is optional.

## API Reference

### `LucidUI:CreateWindow(config)`

Creates the main window and plays the intro animation (unless disabled).

| Key | Type | Default | What it does |
|---|---|---|---|
| `Name` | string | `"LucidUI"` | Window title |
| `Theme` | string | `"Default"` | Starting theme name |
| `Width` | number | `620` | Width in pixels |
| `Height` | number | `460` | Height in pixels |
| `IntroEnabled` | boolean | `true` | Play the intro on creation |
| `IntroTitle` | string | window name | Intro card title |
| `IntroSubtitle` | string | `"v" + version` | Intro subtitle |
| `IntroTagline` | string | `"Modern interface suite"` | Intro tagline |
| `IntroDuration` | number | `1.6` | Intro length in seconds |
| `IntroSkipOnInput` | boolean | `true` | Click or keypress to skip |

### `Window:CreateTab({ Name = "..." })`

Adds a tab to the strip. Returns a Tab object.

### `Tab:CreateSection(nameOrConfig)`

Creates a collapsible section. Pass a string for a simple name, or a table for more control:

```lua
Tab:CreateSection({ Name = "Options", Collapsible = true, StartExpanded = true })
```

### Elements

Every element accepts an optional `Flag` string. If set, the element's value is saved with the config and restored on load.

| Method | Args | What it does |
|---|---|---|
| `Section:CreateButton` | `{ Name, Callback }` | A clickable button |
| `Section:CreateToggle` | `{ Name, CurrentValue, Flag, Callback }` | On/off switch |
| `Section:CreateSlider` | `{ Name, Range, Increment, CurrentValue, Flag, Callback }` | Draggable slider |
| `Section:CreateDropdown` | `{ Name, Options, CurrentOption, Flag, Callback }` | Select from a list |
| `Section:CreateKeybind` | `{ Name, CurrentKeybind, Flag, Callback }` | Capture a key press |
| `Section:CreateInput` | `{ Name, Placeholder, CurrentValue, Flag, Callback }` | Text field |
| `Section:CreateTextDisplay` | `{ Title, Content }` | Read-only text block |

### `LucidUI:Notify({ Title, Message, Duration, Accent })`

Shows a glass toast in the top-right. `Duration` defaults to 4 seconds.

### `LucidUI:ShowIntro(opts)`

Runs the intro manually — useful if you have an auth or key flow before the main window.

```lua
LucidUI:ShowIntro({
    Title = "Loading",
    Subtitle = "v2.0.0",
    Tagline = "by Kyo",
    Duration = 2.0,
    OnComplete = function()
        print("Intro done")
    end,
})
```

### Settings Panel

Call `Window:BuildSettingsPanel()` once after `CreateWindow` to enable the gear icon. It gives users:

- **Theme** — switch between `Default`, `Custom`, and any saved themes
- **Custom Theme** — 6 live color editors + save/load/delete
- **Background Image** — URL input, auto accent detection, transparency slider
- **Configs** — save, load, and delete named config slots
- **About** — version info

## Executor Support

LucidUI doesn't use anything exotic — just standard Roblox APIs and a `Compat` layer for file operations. If your executor runs Roblox scripts at all, there's a very good chance it works here.

If you're on something not listed, try it anyway. The only features that depend on executor-specific APIs are:

- **Config saving** — needs `writefile`, `readfile`, `isfolder`, `makefolder`, `listfiles`
- **Background image from URL** — needs `getcustomasset` and `writefile`
- **Auto accent detection** — needs `AssetService:CreateEditableImageAsync`

If any of those are missing, LucidUI shows a notification and the rest of the UI keeps working. Nothing crashes.

## Development

### Building

The library is split into modules under `src/`. To build the single-file distribution:

```bash
python build.py
```

That concatenates the modules in order and writes `dist/lucidui.lua` — the file your users `loadstring`.

### Module Structure

```
src/
├── 00_compat.lua         -- Compat layer + serialization
├── 01_helpers.lua        -- Create, Tween, Ease, Clamp
├── 02_themes.lua         -- Themes, DeriveTheme
├── 03_icons.lua          -- Frame-based icons
├── 04_intro.lua          -- ShowIntro
├── 05_notifications.lua  -- Notify
├── 06_window.lua         -- CreateWindow
├── 07_settings.lua       -- BuildSettingsPanel
├── 08_tab.lua            -- CreateTab, CreateSection
└── 09_elements.lua       -- All Create* elements
```

### Contributing

If you find a bug or want to add a feature, open an issue or PR. Keep the `Compat` layer in mind — anything that touches the file system needs to go through it, or it'll break on executors without those functions.
