# LucidUI

**A modern, glass-morphism interface library for Roblox.**

Built for stability, cross-executor compatibility, and a premium look — no deprecated dependencies, no key systems, no bloat.

## Why LucidUI

Most Roblox UI libraries are either abandoned, buggy on half the executors, or so heavy they lag the game. LucidUI is a single `loadstring` with zero external dependencies that gracefully degrades when your executor doesn't support a feature instead of erroring out.

- 🧊 **Glass-morphism design** — rounded translucent panels, specular gradients, accent glow
- 🎬 **Animated intro screen** — loading card with shimmer progress and particle burst, skippable with a click
- 🎨 **Live theme switching** — 7 presets + custom theme editor, colors cross-fade over 0.3s
- 💾 **Config slots** — save, load, and delete named profiles. The `default` slot is locked
- 🖼️ **Background images** — asset IDs, `rbxassetid://` URLs, and direct `https://` links
- 🎯 **Auto accent detection** — samples image pixels with a hue-histogram to pick a matching accent color
- 🔔 **Glass notifications** — toasts with adaptive accent bars
- ✨ **Premium polish** — ripple on press, glow on hover, quiet UI sounds
- 📱 **Mobile-friendly** — touch drag, responsive scaling, compact mode
- 🪟 **Traffic-light controls** — minimize to header or collapse to a floating pill
- 🌐 **Cross-executor** — tested on Delta, Solara, Wave, Xeno, Krnl, Fluxus, Synapse

## Install

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyotaah/lucidui/main/dist/lucidui.lua"
))()
```

> `dist/lucidui.lua` is auto-generated by `build.py` from the `src/` folder on every push.

## Quick Start

Ten lines to a working hub:

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyotaah/lucidui/main/dist/lucidui.lua"
))()

local Window = LucidUI:CreateWindow({ Name = "My Hub" })
Window:BuildSettingsPanel()

local Tab     = Window:CreateTab({ Name = "Main", Icon = "zap" })
local Section = Tab:CreateSection({ Name = "Features", StartExpanded = true })

Section:CreateButton({
    Name = "Click Me",
    Callback = function()
        LucidUI:Notify({ Title = "Done", Message = "You clicked the button." })
    end,
})
```

## Full Example

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyotaah/lucidui/main/dist/lucidui.lua"
))()

local Window = LucidUI:CreateWindow({
    Name          = "My Hub",
    Theme         = "Default",
    Width         = 640,
    Height        = 480,
    IntroEnabled  = true,
    IntroTitle    = "My Hub",
    IntroSubtitle = "v1.0.0",
    IntroTagline  = "Built with LucidUI",
    IntroDuration = 2.8,
})

Window:BuildSettingsPanel()

-- Main tab
local MainTab = Window:CreateTab({ Name = "Main", Icon = "home" })
local MainSec = MainTab:CreateSection({ Name = "General", StartExpanded = true })

MainSec:CreateToggle({
    Name         = "Enable Feature",
    CurrentValue = false,
    Flag         = "EnableFeature",
    Callback     = function(state) print("Feature:", state) end,
})

MainSec:CreateSlider({
    Name         = "Speed",
    Range        = {1, 100},
    Increment    = 1,
    CurrentValue = 50,
    Flag         = "Speed",
    Callback     = function(value) print("Speed:", value) end,
})

MainSec:CreateDropdown({
    Name          = "Mode",
    Options       = { "Balanced", "Performance", "Quality" },
    CurrentOption = "Balanced",
    Flag          = "Mode",
    Callback      = function(option) print("Mode:", option) end,
})

-- Settings tab
local SettingsTab = Window:CreateTab({ Name = "Config", Icon = "settings" })
local SettingsSec = SettingsTab:CreateSection({ Name = "Hotkeys", StartExpanded = true })

SettingsSec:CreateKeybind({
    Name           = "Toggle Menu",
    CurrentKeybind = Enum.KeyCode.RightShift,
    Flag           = "MenuKey",
    Callback       = function(key) print("Bound to:", key.Name) end,
})

SettingsSec:CreateInput({
    Name        = "Username Filter",
    Placeholder = "type here...",
    Flag        = "UsernameFilter",
    Callback    = function(text) print("Filter:", text) end,
})

SettingsSec:CreateTextDisplay({
    Title   = "Info",
    Content = "Config saves automatically via the Flag field on each element.",
})
```

## API Reference

### `LucidUI:CreateWindow(config)`

Creates the main window. Plays the intro unless `IntroEnabled = false`.

| Key | Type | Default | Description |
|---|---|---|---|
| `Name` | string | `"LucidUI"` | Window title |
| `Theme` | string | `"Default"` | Starting theme name |
| `Width` | number | `620` | Width in pixels |
| `Height` | number | `460` | Height in pixels |
| `IntroEnabled` | boolean | `true` | Play the intro on creation |
| `IntroTitle` | string | window name | Intro card title |
| `IntroSubtitle` | string | `"v0.9.0"` | Intro subtitle / version chip |
| `IntroTagline` | string | `"Modern interface suite"` | Intro tagline |
| `IntroDuration` | number | `2.8` | Intro length in seconds |
| `IntroSkipOnInput` | boolean | `true` | Click or keypress skips the intro |

### Window Methods

| Method | Description |
|---|---|
| `Window:BuildSettingsPanel()` | Populates the gear menu. Call once after `CreateWindow`. |
| `Window:CreateTab({ Name, Icon })` | Adds a tab to the strip. Returns a Tab object. |
| `Window:SetTheme(name)` | Switches theme with a smooth fade |
| `Window:SetVisible(bool)` | Show/hide the entire window |

### `Tab:CreateSection(name | config)`

Creates a collapsible section. Pass a string or `{ Name, StartExpanded }`.

### Elements

All elements accept an optional `Flag` string. If set, the value is saved with the config.

| Method | Args | Description |
|---|---|---|
| `Section:CreateButton` | `{ Name, Callback }` | Clickable button with ripple + glow |
| `Section:CreateToggle` | `{ Name, CurrentValue, Flag, Callback }` | On/off switch |
| `Section:CreateSlider` | `{ Name, Range, Increment, CurrentValue, Flag, Callback }` | Draggable numeric slider |
| `Section:CreateDropdown` | `{ Name, Options, CurrentOption, Flag, Callback }` | Option selector |
| `Section:CreateKeybind` | `{ Name, CurrentKeybind, Flag, Callback }` | Key capture input |
| `Section:CreateInput` | `{ Name, Placeholder, CurrentValue, Flag, Callback }` | Text field |
| `Section:CreateTextDisplay` | `{ Title, Content }` | Read-only auto-sizing text block |

### `LucidUI:Notify({ Title, Message, Duration, Accent })`

Shows a glass toast in the top-right corner. `Duration` defaults to 4 seconds.

Tabs accept an `Icon` name. Every icon is built from Frames, so it renders identically on any device.

| Icon | Icon | Icon | Icon | Icon |
|---|---|---|---|---|
| `dot` | `bars` | `diamond` | `cross` | `plus` |
| `check` | `shield` | `gavel` | `star` | `coins` |
| `person` | `eye` | `lock` | `unlock` | `play` |
| `pause` | `stop` | `bell` | `home` | `settings` |
| `sword` | `target` | `flame` | `crown` | `zap` |

## Themes

Seven presets ship by default. Switch at runtime with `Window:SetTheme("Nebula")` or via the gear menu.

| Theme | Description |
|---|---|
| `Default` | Dark glass with blue accent |
| `Light` | Clean light mode |
| `Nebula` | Purple cosmic palette |
| `Midnight` | Deep blue with soft edges |
| `Dracula` | Classic purple on charcoal |
| `Tokyo Night` | Muted indigo tones |
| `Forest` | Green glass with soft edges |

**Custom themes** — open the gear icon → Custom Theme. Six color pickers (Background, Surface, Surface Hover, Accent, Border, Text) apply live. Click **Save As** to store the theme under a custom name.

**Saved themes** — every saved theme appears in the Theme dropdown and in the Saved Themes list. Click to load, click the `x` to delete.

## Background Images

Open the gear icon → Background Image. Supports:

- **Asset IDs** — `12345678`
- **Asset URLs** — `rbxassetid://12345678`
- **Direct image URLs** — `https://i.imgur.com/XXXXX.jpg`

HTTP URLs require `getcustomasset` and `writefile` in your executor. If either is missing, you'll get a toast telling you so.

**Auto Accent** samples the image, runs a hue-histogram over saturated pixels, and applies the dominant color as the UI accent.

## Config System

Every element with a `Flag` string gets saved to `LucidUI/Configs/<slot>.json`. The `default` slot is locked and cannot be deleted.

Save and load from the Config section in the gear menu, or programmatically:

```lua
Window:SaveConfig("slot1")
Window:LoadConfig("slot1")
```

Custom themes save to `LucidUI/Themes/<name>.json`.

## Intro Screen

```lua
LucidUI:ShowIntro({
    Title        = "Loading",
    Subtitle     = "v1.0.0",
    Tagline      = "Preparing interface",
    Duration     = 2.8,
    SkipOnInput  = true,
    OnComplete   = function()
        print("Intro finished")
    end,
})
```

For long operations (downloads, etc.), pass custom stages that report progress:

```lua
LucidUI:ShowIntro({
    Stages = {
        { text = "Loading modules...", pct = 0.20, task = function() task.wait(0.5) end },
        {
            text = "Downloading assets...",
            pct  = 0.90,
            task = function(report)
                for i = 1, 10 do
                    task.wait(0.1)
                    report(i / 10)
                end
            end,
        },
        { text = "Ready", pct = 1.00, task = function() task.wait(0.4) end },
    },
})
```

Each `task` receives a `report(subProgress)` callback. Call it with a value from 0 to 1 to advance the bar mid-stage.

LucidUI uses standard Roblox APIs plus a `Compat` layer around file operations. If your executor runs Roblox scripts at all, there's a very good chance it works here.

### Only three features depend on executor-specific APIs

- **Config saving** — needs `writefile`, `readfile`, `isfolder`, `makefolder`
- **Background image from HTTP** — needs `getcustomasset` and `writefile`
- **Auto accent detection** — needs `AssetService:CreateEditableImageAsync`

If any are missing, LucidUI shows a toast and the rest of the UI keeps working.

## Development

### Build

```bash
python build.py
```

Concatenates every `src/*.lua` in sorted order into `dist/lucidui.lua`. GitHub Actions runs this automatically on push to `main`.

### Module structure

```
src/
├── 00_compat.lua         Compat layer + JSON serialization
├── 01_helpers.lua        Services, easing, constructors, glass
├── 01b_polish.lua        Ripple, hover glow, UI sounds
├── 02_themes.lua         7 preset themes + derivation
├── 03_icons.lua          Frame-based gear icon
├── 04_intro.lua          Animated intro screen
├── 05_notifications.lua  Glass toast system
├── 06_window.lua         Window shell, drag, resize, settings container
├── 07_settings_a.lua     Theme dropdown, custom theme editor, saved themes
├── 07_settings_b.lua     Background image, auto accent, configs, about
├── 08_tab.lua            Tabs, sections, 25 icons
└── 09_elements.lua       Button, Toggle, Slider, Dropdown, Keybind, Input, TextDisplay
```

### Contributing

If you find a bug or want to add a feature, open an issue or PR. Keep the `Compat` layer in mind — anything that touches the file system must go through it.
