# LucidUI

A modern, glass-morphism interface library for Roblox. Built for stability, cross-executor compatibility, and a premium look — no deprecated dependencies, no key systems, no bloat.

![Version](https://img.shields.io/badge/version-0.9.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

---

## Features

- **Glass-morphism design** — rounded translucent panels, specular gradients, accent glow
- **Animated intro screen** — loading card with shimmer progress, skip on click/keypress
- **Live theme editor** — 6 editable colors, real-time preview, saved as JSON
- **Config slots** — multiple saved profiles, `default` slot is locked
- **Background image support** — asset IDs, `rbxassetid://` URLs, or HTTP(S) links via `getcustomasset`
- **Auto accent detection** — samples image pixels with `EditableImage` to pick a matching accent color
- **Notification system** — glass toasts with adaptive accent bars
- **Mobile-friendly** — touch drag, viewport-responsive scaling, compact mode
- **Minimize to pill** — X button collapses the window to a floating draggable pill
- **Cross-executor** — Delta, Solara, Wave, Xeno, Krnl, Fluxus, Synapse
- **No external dependencies** — single `loadstring`, nothing else required

## Install

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyootah/lucidui/main/dist/lucidui.lua"
))()
```

> **Note:** `dist/lucidui.lua` is auto-generated by `build.py` from the `src/` folder. If it doesn't exist yet, run the build or wait for the first release.

## Quick Start

```lua
local LucidUI = loadstring(game:HttpGet(
    "https://raw.githubusercontent.com/Kyootah/lucidui/main/dist/lucidui.lua"
))()

local Window = LucidUI:CreateWindow({
    Name = "My Hub",
    Width = 620,
    Height = 460,
})

Window:BuildSettingsPanel()

local MainTab = Window:CreateTab({ Name = "Main" })
local Section = MainTab:CreateSection({
    Name = "Options",
    Collapsible = true,
    StartExpanded = true,
})

Section:CreateToggle({
    Name = "Enable Feature",
    CurrentValue = false,
    Flag = "MyFeature",
    Callback = function(state)
        print("Toggled:", state)
    end,
})

Section:CreateSlider({
    Name = "Speed",
    Range = {1, 100},
    Increment = 1,
    CurrentValue = 50,
    Flag = "Speed",
    Callback = function(value)
        print("Speed:", value)
    end,
})

Section:CreateButton({
    Name = "Do Thing",
    Callback = function()
        LucidUI:Notify({ Title = "Done", Message = "Action completed" })
    end,
})
```

## API Reference

### `LucidUI:CreateWindow(config)`

Creates the main window and (by default) plays the intro animation.

| Key | Type | Default | Description |
|---|---|---|---|
| `Name` | string | `"LucidUI"` | Window title |
| `Theme` | string | `"Default"` | Initial theme name |
| `Width` | number | `620` | Width in pixels |
| `Height` | number | `460` | Height in pixels |
| `IntroEnabled` | boolean | `true` | Play intro on creation |
| `IntroTitle` | string | window name | Intro card title |
| `IntroSubtitle` | string | `"v" + version` | Intro subtitle |
| `IntroTagline` | string | `"Modern interface suite"` | Intro tagline |
| `IntroDuration` | number | `1.6` | Intro duration in seconds |
| `IntroSkipOnInput` | boolean | `true` | Allow click/keypress to skip |

### `Window:CreateTab({ Name = "..." })`

Creates a tab in the tab strip. Returns a Tab object.

### `Tab:CreateSection(nameOrConfig)`

Creates a collapsible section. Accepts either a string name or a config table:

```lua
Tab:CreateSection({ Name = "Options", Collapsible = true, StartExpanded = true })
```

### Elements

All elements accept a `Flag` (string) which enables config persistence.

| Method | Args | Description |
|---|---|---|
| `Section:CreateButton` | `{ Name, Callback }` | Clickable button |
| `Section:CreateToggle` | `{ Name, CurrentValue, Flag, Callback }` | Boolean toggle |
| `Section:CreateSlider` | `{ Name, Range, Increment, CurrentValue, Flag, Callback }` | Numeric slider |
| `Section:CreateDropdown` | `{ Name, Options, CurrentOption, Flag, Callback }` | Select dropdown |
| `Section:CreateKeybind` | `{ Name, CurrentKeybind, Flag, Callback }` | Key capture |
| `Section:CreateInput` | `{ Name, Placeholder, CurrentValue, Flag, Callback }` | Text input |
| `Section:CreateTextDisplay` | `{ Title, Content }` | Read-only text block |

### `LucidUI:Notify({ Title, Message, Duration, Accent })`

Shows a glass notification toast in the top-right corner.

### `LucidUI:ShowIntro(opts)`

Manually plays the intro screen. Useful for auth flows.

```lua
LucidUI:ShowIntro({
    Title = "Loading",
    Subtitle = "v2.0.0",
    Tagline = "by Kyo",
    Duration = 2.0,
    OnComplete = function()
        print("Intro done")
    end,
})
```

### Settings Panel

Call `Window:BuildSettingsPanel()` once after `CreateWindow` to enable the settings gear. It provides:

- **Theme** — switch between `Default`, `Custom`, and saved themes
- **Custom Theme** — 6 live color editors + save/load/delete
- **Background Image** — URL input, auto accent, transparency slider
- **Configs** — save/load/delete named config slots
- **About** — version info

File system operations (`writefile`, `readfile`, `isfolder`, `makefolder`, `listfiles`) are wrapped in a `Compat` layer — if the executor lacks any, saves fail gracefully with a notification instead of erroring out.

## Development

### Build

The library is split into modules under `src/`. To build the single-file distribution:

```bash
python build.py
```

This concatenates modules in order and writes `dist/lucidui.lua`.

### Module Structure

```
src/
├── 00_compat.lua         -- Compat layer + serialization
├── 01_helpers.lua        -- Create, Tween, Ease, Clamp
├── 02_themes.lua         -- Themes, DeriveTheme
├── 03_icons.lua          -- Frame-based icons
├── 04_intro.lua          -- ShowIntro
├── 05_notifications.lua  -- Notify
├── 06_window.lua         -- CreateWindow
├── 07_settings.lua       -- BuildSettingsPanel
├── 08_tab.lua            -- CreateTab, CreateSection
└── 09_elements.lua       -- All Create* elements
```
